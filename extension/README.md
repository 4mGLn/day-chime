# Day Chime browser reader

브라우저 확장 0.4.2 · 2026-11-04

다우오피스 홈 위젯의 날짜·출퇴근 시각을 읽어 로컬 Rust 호스트에 전달하는 Chromium Manifest V3 확장입니다.

## 간편 설치

[프로젝트 설치 안내](../README.md#빠른-설치)를 따르세요. 설치 스크립트가 회사별 URL을 적용하고 확장 폴더를 안내합니다.
Brave/Chrome 확장 관리 화면에서 개발자 모드로 폴더를 로드한 뒤, 표시되는 확장 ID로 로컬 호스트를 연결합니다.
사용자가 로드할 폴더는 저장소 원본이 아니라 **설치 스크립트가 안내한 회사별 설정이 적용된 폴더**입니다.
원본은 안전한 중립 주소 `https://example.daouoffice.com/home`을 사용합니다.

```bash
~/.local/bin/day-chime-setup --extension-id YOUR_32_LETTER_EXTENSION_ID
```

기본 브라우저는 Brave이며 Chrome/Chromium 설치에서는 처음에 지정한 브라우저를 유지하거나 `--browser`로 선택할 수 있습니다.

## 동작

- Brave 시작 시 오늘 수집이 완료되지 않았으면 회사 홈을 비활성 탭으로 엽니다.
- 오늘 출근시간을 로컬 호스트가 정상 접수하면 성공을 저장하고 자신이 연 비활성 탭을 닫습니다.
- 아직 출근 전이거나 연결 실패이면 실행 중 15분마다 다시 시도합니다. 날짜 기준은 Asia/Seoul입니다.
- 기존에 사용자가 열거나 직접 활성화한 탭은 닫지 않습니다.
- 로그인 화면 이동을 감지하면 직접 로그인을 기다립니다. URL 변경 이벤트를 읽지 못할 경우에는 타임아웃 후 재시도 안내를 표시합니다.
- 사용자가 홈을 열어 두면 30초마다 수정·퇴근 기록도 전달합니다.
- 오늘 출근 확인 알림을 받으면 브라우저를 닫아도 데몬의 퇴근 알림은 유지됩니다.
- 비밀번호·쿠키·메일은 읽지 않고 출퇴근 버튼도 누르지 않습니다.

권한은 `nativeMessaging`, `alarms`, `storage`이며 전체 탭 열람 권한은 요구하지 않습니다.
회사별 `site.js`와 manifest 접근 범위는 설치 도구가 함께 생성합니다.

## 업데이트

설치 명령을 다시 실행한 뒤 확장 관리 화면에서 Day Chime 카드의 새로고침을 누릅니다.
같은 확장 폴더를 유지하면 ID도 유지할 수 있습니다. ID가 바뀌면 새 ID로 연결 명령을 실행하세요.

## 개발 검증

```bash
node extension/tests/reader.test.cjs
node extension/tests/background.test.cjs
```

단위 테스트의 모의 브라우저 증거는 실제 로그인·자동 탭·화면 알림 검증과 구분합니다.
아이콘 원본과 크기별 PNG는 [assets](../assets/)에 있습니다.

## 출근 시각 확인

수집 성공 후 확장 팝업에서 **출근 시간: 09:50**을 확인할 수 있습니다. 이전 날짜 기록은 날짜도 표시합니다.
기존 버전에서 업데이트할 때는 확장 관리 화면의 새로고침을 누르면 표시 정보를 자동으로 다시 수집합니다.

## 팝업 조작

상단 출근 시간 카드는 데이터가 없을 때도 안내와 함께 항상 표시됩니다. 오른쪽 위 ↻ 버튼은 확장 프로그램 재시작이 아니라 실제 출근 기록 재조회입니다.
자동 수집 토글과 조회 간격을 저장해 브라우저를 다시 시작해도 유지합니다. 기본은 자동 수집 켜짐·15분이며, 간격은 1–1440분입니다.
자동 수집을 끄면 예약 조회와 홈 탭의 자동 읽기가 중단됩니다. 수동 새로고침은 계속 사용할 수 있고 이미 저장한 기록의 퇴근 알림도 유지합니다.

`day-chime update`는 등록된 확장 폴더의 파일도 함께 갱신합니다. 별도 경로는 `update --force --extension-dir /path/to/extension`으로 한 번 등록할 수 있습니다. 갱신 후 브라우저 확장 관리 화면에서 Day Chime을 한 번 새로고침하세요.
